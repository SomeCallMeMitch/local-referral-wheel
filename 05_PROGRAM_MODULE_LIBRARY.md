# 05 --- Program Module Library

The business should be modular. Not every chapter or member needs every component.

## Core Module A --- Referral Wheel

Purpose: systematically create trusted, trigger-based referrals.

Components:
- member ICP;
- category exclusivity;
- trigger-event library;
- "listen for" phrases;
- referral scripts;
- warm handoff templates;
- response SLA;
- attribution;
- status updates;
- close/loss reason;
- referral quality score;
- reciprocal-balance analysis;
- partner-pair opportunities.

## Core Module B --- Growth Scorecard

Track a small set of business metrics. Avoid requiring a full accounting integration initially.

Potential inputs:
- monthly revenue;
- leads;
- appointments/estimates;
- close rate;
- average ticket;
- repeat purchase;
- referrals;
- reviews;
- gross margin (optional);
- marketing spend (optional).

Output:
- trend;
- gaps;
- highest-leverage growth opportunity;
- annualized value of a small improvement.

## Advisory Module --- Hot Seat / Business Issue

Use an independently designed facilitation method:
1. member states decision/problem and desired outcome;
2. group asks clarifying questions before advising;
3. identify constraints and facts;
4. surface options;
5. member chooses next action;
6. action recorded with due date;
7. next meeting reviews outcome.

This is generic process design and should not reproduce a competitor's proprietary methodology.

## Module design rule

Each module should specify: **Input → Process → Output → Metric → Follow-up.**

That makes it software-ready and teachable to future facilitators.
