## What this exercise changes
The most attractive first network is not necessarily the one with the highest-ticket event. Maintenance visits create repeated chances to notice adjacent needs, whereas inheritance and business retirement may be valuable but rare and sensitive. Start with frequent, bounded events and a short path to useful handoffs.

A property manager could be a powerful anchor yet a poor reciprocal paying member. This supports testing an anchor-funded or free-source model rather than forcing equal membership roles. A transaction-centered real-estate wheel is a distinct alternative, not interchangeable with a household service network.

Before using any chain, ask two providers to reconstruct recent actual examples, including when no downstream purchase occurred. This protects against a diagram that looks valuable but has little real activity.
